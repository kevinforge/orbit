01 / THE IDEA

工具越来越多，
上下文不该越来越碎。

Orbit 不是又一个聊天窗口。它是一个把目标、分工、审批和结果放在一起的控制面，让 Agent 的能力变成一支真正可调度的团队。

02 / BUILT FOR REAL WORK

少一点魔法，
多一点掌控。

Orbit 把复杂性放在该放的位置：运行时留在适配器，状态留在本地，会话留在你手里。

05 / GET STARTED

把 Orbit 放进
你的工作区。

需要 Node.js 22 或更高版本，以及至少一个已登录的运行时。

从命令行开始。
