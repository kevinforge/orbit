本地优先的多 Agent 工作台

一个碳基，可以拥有一支硅基团队

把 Claude Code、Codex 与 CodeBuddy 汇聚到同一个工作区和会话中，协同完成每一个目标。 Orbit 负责路由、队列、审批与历史，由你决定谁来做、何时交接。

在 GitHub 上查看 快速开始
$ npm install -g @kevinforge/orbit

不要安装公开 npm 上那个无关的 orbit 包。

$ git clone https://github.com/kevinforge/orbit.git $ cd orbit $ npm ci $ npm run build $ npm run dev

随后在浏览器打开 http://localhost:4317。

核心理念

协作 = 碳基判断 × 硅基行动

Orbit 把一个本地项目目录变成会话式协作工作台。你负责判断与方向，数字员工负责并行执行、交叉核验与结果交付。

  • ONE CONVERSATION

    一个会话，多个专家

    目标、过程与结果保留在同一条可见的工作流里，不用在多个窗口之间复制上下文。

  • HUMAN-DIRECTED ROUTING

    由人控制路由

    用 @显示名称: 明确指派；或不写指派，把目标交给内部监工协调启用的团队。

  • LOCAL-FIRST & RECOVERABLE

    本地优先，执行可恢复

    工作区、消息、会话与附件保存在本机 ~/.orbit；每个员工独立排队，支持审批、取消与失败恢复。

设计思路

把协作过程留在可见的工作流里

Orbit · 复杂协作
  • 普通对话与一位员工聚焦沟通
  • 简单协作明确组织多个员工交接
  • 复杂协作目标交给监工拆解与收敛
把登录流程的改进合并发布并回报结果。
已拆解为：方案评估 → 并行实现 + 回归清单 → 核验 → 汇总。
@蔡一平: 实现修复。@田小坑: 准备回归检查清单。
Orbit · 协作洞察
  • 已完成范同经澄清范围与验收标准
  • 已完成甄架构提出实现方案
  • 进行中蔡一平修改文件并运行检查
  • 排队中田小坑验证行为并报告回归

消息历史、运行时会话与终端记录持久化在 ~/.orbit。

Orbit · 统一 ACP 运行时层
Claude Code Codex CodeBuddy
↕ 统一 ACP 适配层 ↕ 本地消息存储 · ~/.orbit

三种运行时都走 ACP v1（换行分隔的 JSON-RPC），运行时差异留在各自适配器内。

开始使用

三分钟跑起来

需要 Node.js 22 或更高版本，以及至少一个已登录的运行时。

  • QUICK INSTALL

    快速安装

    通过 npm 全局安装并启动。

    $ npm install -g @kevinforge/orbit $ orbit

    随后打开 http://localhost:4317。

  • FROM SOURCE

    从源码运行

    克隆仓库后本地构建并启动开发服务。

    $ git clone https://github.com/kevinforge/orbit.git $ cd orbit $ npm ci $ npm run build $ npm run dev

    或从 GitHub Releases 下载平台安装包。

也可阅读 中文快速上手 了解首次使用流程。
